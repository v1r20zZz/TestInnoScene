# Конструктор шахматных диаграмм

**Версия разработки 0.1.0. Это исходный проект, не готовый Windows-установщик.** Полное ТЗ не выполнено. Основной редактор и экспорт проверены в Linux/Qt offscreen. Windows EXE не создан.

## Архитектура

- model.py: независимая модель, FEN/PGN, история, атомарный ZIP-проект.
- render.py: единый QPainter-рендерер для экрана и экспорта, SVG-фигуры, текст в контурах.
- canvas.py: Qt Graphics View, размещение и перемещение, рисование.
- app.py: русский интерфейс, панели, шаблоны, ресурсы, несколько диаграмм.
- export.py: RGB, ICC TIFF, векторный CMYK PDF через Ghostscript, страницы A4/A5.
- preflight.py: начальная проверка растра и обрезания фигур.
- tests/: автоматические проверки модели, экспорта и отдельных действий мышью.
- examples/: проект и примеры RGB/CMYK.
- ChessDiagram.spec, installer/setup.iss, scripts/build-windows.ps1: сценарии сборки.
- .github/workflows/windows.yml: Windows GitHub Actions, не запускался.

## Запуск исходного проекта разработчиком

Python 3.12 x64. Создайте venv, затем:

```
python -m pip install -r requirements-dev.txt
python main.py
python -m pytest tests -q
```

Для headless-тестов установите QT_QPA_PLATFORM=offscreen. Для тестирования CMYK задайте TEST_CMYK_ICC — путь к CMYK-профилю. Ghostscript нужен для CMYK PDF, но не для CMYK TIFF. Он ищется в PATH или в папке ghostscript внутри проекта/пакета.

## Windows-сборка

GitHub Actions устанавливает Python 3.12, Inno Setup и Ghostscript на машине сборки, прогоняет тесты, вызывает PyInstaller и собирает EXE через Inno Setup. Сценарий ещё не запускался. Для локальной сборки разработчику нужны Python и Inno Setup 6; Ghostscript следует заранее скопировать в папку ghostscript. Затем scripts/build-windows.ps1.

Кандидат сборки нельзя считать проверенным релизом до тестирования установки, удаления, открытия файлов двойным нажатием, HiDPI, печати и запуска без Python/интернета на чистых Windows 10 и 11. Цифровой подписи нет.
