# Версия 0.2.0 — редактор и студия публикации

Предварительный выпуск. Это развитие Windows-программы 0.1.0, а не подтверждение готовности к коммерческому релизу.

## Реализовано

- Студия экспорта одной диаграммы: предпросмотр, физический размер, DPI, прозрачность, формат, проверка растровых ресурсов и наличия CMYK-профиля.
- Студия публикации: A4/A5, книжная и альбомная ориентация, сетка, поля и интервалы, заголовок, подпись внизу, номера страниц и заданий, сторона хода, строки для ответов. RGB/ICC CMYK PDF, векторная доска и текст в контурах. Превью и PDF используют один механизм вёрстки. Длинные подписи переносятся на две строки, затем сокращаются многоточием.
- Экспорт отдельным процессом. Редактор остаётся доступным. Используется снимок проекта: последующее редактирование не меняет начатый экспорт. Отмена завершает обработку текущего файла, не заменяя его; ранее завершённые файлы пакета сохраняются. Изменение состояния экспортного процесса не сохраняет основной проект вместо пользователя.
- Ручки узлов стрелок и графики, перенос с привязкой к клеткам, отмена перетаскивания Escape и undo/redo. Для кривой можно добавить третью управляющую точку через свойства, затем перемещать её ручку.
- Выбор фигуры превращения в режиме легальных ходов; изменение стороны хода; импорт всех партий PGN отдельными диаграммами, с проверкой всего импорта перед изменением проекта.
- Панель быстрых действий и поиск команд Ctrl+K. Доступность undo/redo отражает историю.
- Уникальная резервная копия каждого сеанса; блокировка активных сеансов при поиске восстановления; корректное чтение кириллицы в избранном.
- Сохранена совместимость с проектами версии 0.1.0.

| Ориентир | Проверенная возможность | Вывод для нашего продукта |
|---|---|---|
| ChessBase 18, Diagram List | Несколько диаграмм на страницах, перенос списка в текстовый редактор через RTF | Реализована студия учебных листов с предпросмотром; редактируемый DOCX/RTF пока отсутствует |
| Apronus Diagram Editor | Стрелки, выделенные клетки, текст, PNG/SVG/WEBP, сторона хода, стили | Добавлены визуальный экспорт и ручки объектов; не копировались код и изображения конкурента |

## Перед продажей

1. Определить модель лицензирования. Приложение уже опубликовано под GPL-3.0-or-later и использует python-chess GPL-3.0+. GPL разрешает продажи при соблюдении условий распространения и предоставления соответствующего исходного кода. Покупателям нельзя запрещать права, предоставленные GPL. Закрытая версия потребует отдельного аудита и замены несовместимых зависимостей или получения необходимых лицензий; удаление LICENSE эту задачу не решает.
2. Разобрать полный комплект распространения Ghostscript (AGPL или коммерческая лицензия), Qt/PySide6 (условия LGPL/GPL/коммерческой лицензии), шрифтов и графики. Ссылки ниже — сведения правообладателей, а не юридическое заключение о готовности данного пакета к продаже.
3. Провести ручную приёмку на чистых Windows 10/11, на 100/150/200% масштабе, без Python и инструментов разработчика; проверить обновление поверх 0.1.0, восстановление после аварии и большие проекты.
4. Проверить типографские файлы в InDesign и согласовать ICC с типографией. PDF/X не заявлен; профиль монитора и ICC всех входных изображений ещё не управляются полностью.
5. Выбрать издателя, оформить поддержку и пользовательские условия, подписать EXE собственным сертификатом. Цифровая подпись, магазин, оплата, активация и автообновление пока не реализованы. Ключи активации не добавлялись без согласованной модели лицензирования.
6. Следующие продуктовые задачи: миниатюры/поиск и сортировка больших проектов, групповой выбор и трансформация объектов, полноценный редактор кривых, редактируемый экспорт в Word, библиотека авторских наборов фигур, стресс-тесты и ограничение памяти истории.

## Проверка

Результаты автоматической Windows-сборки находятся в GitHub Actions для коммита выпуска. Сборка включает тесты, упаковку, запуск EXE, установку в путь с кириллицей, экспорт установленной программой и удаление. Это не заменяет ручную приёмку на Windows 10/11.
