# Конструктор шахматных диаграмм — руководство 0.1.0

Это версия разработки. Установочный EXE ещё не собран. Полная реализация всех требований ТЗ не завершена; смотрите ОТЧЁТ.md.

## Редактирование

Слева нажмите фигуру, затем клетку, или перетащите фигуру из библиотеки. Для перемещения уже стоящей фигуры включите «Выбор / перемещение». Ластик удаляет фигуры. Ctrl+Z отменяет, Ctrl+Y и Ctrl+Shift+Z повторяют действие. История сохраняет 1000 отменяемых изменений в текущем сеансе; в проект она не записывается.

Колесо мыши меняет масштаб, средняя кнопка перемещает холст. Ctrl+0 вписывает доску в окно. F поворачивает доску. Панели можно изменять, откреплять и закрывать; меню «Вид» возвращает их. Начальная позиция и пустая доска меняют фигуры, оставляя аннотации.

## Оформление

Сторона доски задаётся в миллиметрах; кнопка «Размер в см / px / pt» переводит другие единицы. Пиксели рассчитываются по текущему DPI. Все остальные размеры оформления, поля, смещения, толщины задаются в единицах холста: доска = 640, клетка = 80. Одна единица в мм равна стороне доски / 640. При доске 120 мм и полях 42 общий экспортный квадрат имеет сторону 135,75 мм. Дополнительная ширина/высота холста сохраняет квадратную доску.

Можно менять цвета, градиент, прозрачность, сетку, рамку, координаты и фигуры. Импортированные текстуры вписываются с сохранением пропорций. Непрозрачное пользовательское изображение всей доски закроет её 64 клетки: геометрию такого изображения автор должен проверить самостоятельно.

Координаты с одной стороны — буквы снизу; с двух — снизу и слева; с четырёх — со всех сторон. Вариант «На рамке» использует регулируемый отступ, как «Снаружи»; положение подбирается относительно рамки. Текст в SVG/PDF переводится в контуры.

RGB/HEX выбираются через диалог цвета. Ввод процентов CMYK преобразуется в экранное RGB-приближение средствами Qt; исходные CMYK-компоненты не сохраняются. Настоящая ICC-конвертация выполняется при экспорте.

## Стрелки и обозначения

Правой кнопкой проведите от начала к концу стрелки. Или выберите слева стрелку, ход коня, кривую, дугу, ломаную, линию, овал, прямоугольник, заливку, обводку, крестик, галочку или текст. Настройте цвет, толщину, прозрачность, наконечник, пунктир, точки, два наконечника и двойной контур.

Для ломаной включите режим по точкам, щёлкните точки и нажмите Enter. Esc отменяет незавершённое рисование. Выбранный объект можно переместить, дублировать, удалить и изменить через панель «Выбранный объект». Порядок объекта действует внутри слоя.

Точки редактируются списком JSON: [[x,y],[x,y]]. У кривой третья точка позволяет задать начало, управляющую точку, конец. Координаты относятся к доске со стороны белых и поворачиваются вместе с ней. Редактирование узлов мышью не реализовано. Команда поворота преобразует точки; полноценного поворота текста, изображений и прямоугольных фигур пока нет.

!, ?, !!, ??, !?, ?!, номера и подписи вводятся как текст. Ctrl+Shift+V вставляет изображение из буфера; Ctrl+Shift+C копирует диаграмму в растре.

## Ресурсы

Доступны классический и геометрический векторные наборы. Для собственного набора подготовьте файлы wK, wQ, wR, wB, wN, wP, bK, bQ, bR, bB, bN, bP с расширением SVG/PNG/JPG/BMP. Регистр имён важен. Импорт отдельной фигуры обновляет набор «Пользовательский»; отсутствующие фигуры используют геометрический набор.

Общие настройки размера и отдельные множители белых/чёрных находятся справа. Индивидуальные параметры доступны после выбора фигуры. TTF/OTF можно импортировать во вкладке координат. Ресурсы и пользовательские шрифты включаются в проект. Используйте шрифты, которые разрешено переносить.

## Позиции, проекты, шаблоны

FEN можно импортировать, копировать, вставлять и экспортировать. Список FEN — текстовый файл, по позиции на строку. Импорт PGN читает первую партию. Стрелки клавиатуры переходят по полуходам. В режиме легальных ходов изменения записываются в PGN; ручная расстановка сбрасывает запись партии. Пешка при достижении последней горизонтали автоматически становится ферзём; выбор другой фигуры в интерфейсе пока отсутствует.

Ctrl+S сохраняет .chessdiagram — ZIP с JSON и ресурсами, через временный файл и атомарную замену. Раз в минуту сохраняется резервная копия несохранённого проекта; следующий запуск предлагает восстановление. Одновременные экземпляры приложения могут конфликтовать из-за общей резервной копии.

В нижней панели можно добавлять, переименовывать, дублировать, переставлять и удалять диаграммы. Шаблоны .chesstemplate меняют оформление без изменения позиции. Библиотека поддерживает импорт, экспорт, дублирование, переименование и удаление. Оформление по умолчанию применяется командой «Новый проект». Избранные позиции доступны в меню «Доска».

## Экспорт

Ctrl+E: PNG, SVG, PDF, TIFF, JPEG, BMP. Параметры берутся из текущей диаграммы. PNG и SVG/PDF допускают прозрачный фон; JPEG/BMP получают белый фон. Скрытый слой не экспортируется. Для «только доска» отключите ненужные слои; независимый диалог состава экспорта ещё не сделан.

Одиночный экспорт проверяет разрешение основных растровых ресурсов и возможное обрезание фигур. Проверка пока не покрывает все объекты и пакетный экспорт. Предел растра — 100 мегапикселей.

Для CMYK загрузите профиль типографии на вкладке «Экспорт». CMYK TIFF преобразуется из sRGB через LittleCMS/Pillow с выбранным rendering intent и вложением профиля. CMYK PDF преобразуется через Ghostscript с сохранением векторных контуров и получает OutputIntent с профилем. Без Ghostscript CMYK PDF не создаётся; используйте CMYK TIFF. Это не сертифицированный PDF/X.

Цветопроба предполагает sRGB-монитор. Реальный профиль монитора и встроенные профили импортированных изображений автоматически не учитываются. Примеры используют общий Ghostscript CMYK, не профиль конкретной типографии.

Пакетный экспорт принимает шаблон имени {n:03d}_{name}. Страницы A4/A5 — RGB PDF с выбранными строками, столбцами и интервалами. Длинные заголовки могут не поместиться; автоматическая многострочная вёрстка ещё не реализована.

## Установка

Готового установщика в архиве нет. Сценарии сборки предназначены для разработчика и не проверены на Windows. После успешной будущей сборки конечному пользователю потребуется только ChessDiagramConstructor_Setup.exe; Python устанавливать на его компьютер не потребуется. Подписи сертификатом нет.
