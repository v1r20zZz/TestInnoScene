# Отчёт о реализации и проверке

Дата: 20 октября 2026. Версия: 0.1.0, разработка.

**Главный критерий ТЗ НЕ выполнен: готового Windows EXE нет. Полное приложение со всеми заявленными функциями не завершено. Этот архив — сохранённый результат разработки, а не замена требуемого установщика.**

## Что фактически выполнено

Написано настольное приложение Python/PySide6 с русским интерфейсом. Оно запускается в доступной Linux-среде. Реализованы 64-клеточная доска, корректная начальная позиция, смена стороны, общие настройки оформления, два векторных набора, ресурсы, произвольная расстановка, FEN, первая партия PGN, легальные ходы, основные аннотации, слои, история, переносимый ZIP-проект, резервное сохранение, несколько диаграмм, библиотека шаблонов и избранное.

Реализованы PNG/JPEG/BMP/TIFF/SVG/PDF, ICC CMYK TIFF, CMYK PDF через установленный Ghostscript, цветопроба с предположением sRGB-монитора, пакетный экспорт и RGB PDF страниц A4/A5. Текст экспортируется в контурах; растровые изображения остаются растровыми.

## Среда и результаты проверок

Linux x86_64, Python 3.12.14; PySide6 6.12.0, chess 1.11.2, Pillow 12.3.0, pypdf 6.10.0, pytest 9.1.1. Qt использовался с QT_QPA_PLATFORM=offscreen. Ghostscript установлен в среде. Тестовый профиль: /usr/share/color/icc/ghostscript/default_cmyk.icc.

35 автоматических тестов прошли. Машиночитаемый результат приложен как test-results-linux.xml, текстовый — test-results-linux.txt. Проверены:

- обратимость координат 64 клеток в обеих ориентациях, 32 тёмные клетки, a1 тёмная;
- начальное положение королей, ферзей и пешек;
- FEN, недопустимый FEN без изменения документа;
- история, новая ветвь после отмены, 1000 операций;
- перенос ресурсов и кириллические/казахские имена файлов;
- отказ от повреждённого/неподдерживаемого проекта;
- свободные и легальные ходы, импорт и просмотр PGN;
- экспорт шести графических форматов, прозрачность PNG;
- размеры растра, точные физические размеры PDF и SVG;
- наличие векторных команд в PDF и отсутствие растрирования SVG-фигур;
- CMYK TIFF: четыре канала, вложенный ICC, DPI, совпадение цвета с ICC-преобразованием;
- CMYK PDF: векторные CMYK-команды и вложенный четырёхканальный профиль OutputIntent;
- цветопроба и страницы A4;
- рисование основных аннотаций;
- запуск окна, размещение и перенос фигуры мышью, стрелка правой кнопкой, undo/redo;
- блокировка фигур, сохранение позиции при применении шаблона;
- сохранность существующего файла при отказе экспорта.

Визуально просмотрено окно приложения. Скриншоты использовались только для внутренней проверки. Проверки не означают исчерпывающую приёмку всех возможностей. Не проверялись реальный принтер, Adobe InDesign, калиброванный монитор, десятки тысяч объектов, большие пользовательские наборы SVG и сбой питания во время записи.

## Исправления, выявленные проверками

Исправлено имя перечисления Qt для точки масштабирования. Исправлено округление физических размеров PDF: страницы дополнительно масштабируются с сохранением векторов до точных размеров. Уточнён тип пути тестового ICC. Уменьшена высота нижней панели для увеличения рабочего поля.

## Что нужно для следующего шага

Windows-среда сборки, например предоставленный пользователем репозиторий GitHub с GitHub Actions, позволит выполнить приложенный сценарий и получить кандидата установщика. Затем нужна проверка на чистых Windows 10/11. Одного запуска CI недостаточно для подтверждения всех требований ТЗ. До релиза также нужно устранить перечисленные пробелы, провести приёмку и подготовить лицензионный комплект зависимостей.
